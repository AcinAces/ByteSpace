## How to Run Locally

1. Clone the repo:
```bash
git clone https://github.com/AcinAces/ByteSpace.git
cd ByteSpace
```

2. Install dependencies:
```bash
npm install
```

3. Run the dev server:
```bash
npm run dev
```

Open http://localhost:3000 in your browser.
